## Database Schema
- **Product**: Main entity mit quantity, status, AI results
- **ProductPhoto**: Mit MinIO URLs (url, thumbnailUrl)
- **Analysis**: AI Analysis History
- **Tag**: Many-to-many mit Products
- **AnalysisQueue**: Batch Processing

## Docker Services
- **postgres**: PostgreSQL 16-alpine (Port 5432)
- **pgadmin**: Database Management UI (Port 5050)  
- **minio**: Läuft extern auf Synology (nicht in Docker)
- **app**: Next.js (configured for standalone)

## Commands
```bash
# Docker & Database
docker-compose -f docker-compose.dev.yml up -d  # Start PostgreSQL
npx prisma migrate dev                          # Run migrations
npx prisma studio                               # Database GUI

# Development
npm run dev                                     # Start on :3000
npm run lint                                   # Check ESLint (200+ errors!)
npm run typecheck                             # TypeScript check

# Production Build
docker build -t inventiq:latest .             # Build Docker image
docker-compose up                            # Start all services
```
